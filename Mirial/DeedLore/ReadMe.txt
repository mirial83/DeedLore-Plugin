Deed Lore Reference
Credits: This is a revision on Vinny’s Lost Lore Reference. It has been changed to reorganize the Deeds by Region and has the full complement of deeds to find certain items, locations, deliver items, or kill certain NPCs. Lunarwater’s Waypoint is also used within the revised files.
Introduction: Deed completion does require that you find all locations, complete all quests, collect all items, or kill a certain number of npcs. For the Deeds that do have specific locations for single-find items/locations/NPCs, this plugin will help you to locate those without having to comb through wiki pages for the details and set a manual target location. Please be aware that slayer deeds and deeds requiring a certain number of quests/deeds be completed are not included in this Plugin. The lists of found items are saved separately for each character played.
Installation: The .zip file should be expanded into the folder "My Documents\The Lord of the Rings Online\Plugins" creating a folder named "Mirial" and sub-folders named "DeedLore" and "Common". You may need to create the "Plugins" folder. If the plugin fails to load, the most common reason is that it isn't located in the right folder. There is also an AutoHotKey script named “LocRefresh.ahk” in the DeedLore folder that can be used to trigger repeated heading updates. This requires the AutoHotKey app to be installed from “https://autohotkey.com/download/”.
You have the choice to use the built-in compass or using the Waypoint Arrow. If you choose to use the Waypoint Arrow by Lunarwater, this can be auto-loaded.
Loading: Once LOTRO is running and a character is active, the plugin can be loaded by entering the command "/plugins load deedlore" in the chat window or using the Plugin Manager. When the plugin successfully loads, it will display the message "DL: Deed Lore initialized." It can also automatically open the DL window by setting “Auto-open window” in the Plugin Manager Options tab (that also saves the main window position).
Note: You can assign loading the plugin to a quickslot, like this: "/shortcut 21 /plugins load deedlore" and then use ctrl-9 to load the plugin. (Quickslots are numbered 1-12 for bar 1, 13-24 for bar 2, etc.)
Deed Lore commands: 
All commands for Lost Lore are entered on the chat command line and start with "/dl".
"/dl ?" displays the help text.
"/dl groups" displays a list of known areas.
"/dl deed" displays a list of available deeds that aren’t active, completed, or above level.
"/dl done" displays a list of finished check lists."
/dl part" displays a list of partially completed check lists.
"/dl quest" displays a list of available quests that aren’t active, completed, or above level.
"/dl <group>" (where <group> is a known group) displays a list of object categories within that group.
"/dl show" opens the window interface for Deed Lore. There is an option in the Plugin Manager to auto-open the DL window when the plugin is loaded. Setting this option also saves the current window position.
“/dld <loc>” set the current destination to the coordinates <loc>. This will also be displayed in the “Loc:” field (make an item selection to reset it). If the description of the location includes a waypoint location, it will be set as the map destination. Destinations are marked on the map with a cyan dot and will be removed when changing items or areas (click Map button to refresh).
“/dlm” opens the Deed Lore Map window.
“/dlw” another way of opening the main Deed Lore window.
“/dlw c” Toggles the visibility of the Deed Lore Compass, which is another way to see the distance and heading for the currently selected item.
“/dlw cc” Toggles the visibility of the Compass click panel. When visible, clicking on the compass area around the distance box in the center has the same effect as the Heading button (it updates the distance and heading.
Lost Lore window controls:
"Area" menu selects a map.
"Deed" menu selects a deed to act on. A deed that is marked as Done will be colored green and a deed in progress will be colored white.
"Item" menu selects an object # to display the location of (and possible comment).
“Check List” button opens a list of items for the selected Deed with check boxes to track items that have been collected. A separate list is maintained for each character. If the locations have names, shift-click on the button to replace coordinates with names.
“Done” checkbox is used to indicate that all the items in the collection have been found. Removing a Done check will clear the current list. (Both actions save storage space.)
“Nearest” button finds the nearest item location that hasn’t been Checked and sets the Item menu to it. The Heading and Waypoint buttons are then activated. This can’t be used inside an instance that lacks coordinates.
“Heading” button calculates and displays the distance to the selected item and the relative direction. The direction is displayed as one of 16 compass points, I.e., “N”, “SW”, or “ENE”. If you are at the location when using the button, it will say that it is ‘here’ and if the Lore List window is open (and not in an instance), it will automatically check that location as found. The Compass window and Map widow are also updated by this command. Shift-clicking on this button will open the built-in Compass Windows and enable update clicks. If the compass window is open, the heading message won’t be generated. If the Map window is open, it will also update the player position (red dot) if within the displayed map.
Updating the location for Waypoint can be automated with the “LocRefresh.ahk” script (see install notes). If the script is running, pressing Ctrl-/ will toggle its active state (1 beep=on, 2 beeps=off). While active, it will generate a heading update every 5 seconds (this can be changed in the script). It can also interfere with chat window usage and menu selections, so it should be toggled off when not in use. It will pause when Lotro isn’t the active window and unpause when returning to the game.
"List Items" button lists all the items defined for the selected Deed. If no deed is selected, available Deeds will be listed instead.
"List N-S" button lists all the defined items sorted in North-South order.
"List N-S" button lists all the defined items sorted in East-West order.
“Save Maps” button saves the current map set in the current character’s settings.
“Restore Maps” button loads the last saved map set from the current character’s settings.
“Find what’s here” button will look though all deeds for an exact location match. If found, the Area, Deed and Item # will be set to the found location. Shift-clicking on this button will perform a “Find Nearby” command, to list all areas with a location within 6 units of the current location. If only one is found, it will be set as the current area. If a map set isn’t defined, all found areas will be put in a new set (see below).
“Map” button opens the Deed Lore Map window.
Map sets: Maps can be combined into sets to make them easier to cycle through. Some zones have 4+ maps and cycling through them allows you to easily collect items from multiple maps at a time. The “Map#” field indicates the current map in the set and the total count of maps in the set. If the current map isn’t in the set, it will display as “0”. A count of “0” indicates there isn’t a set defined. To add the current map to the set, click on the “+” button and to remove it, click on the “-” button. Clicking on the “Next” button will cycle to the next map in the set. If the current map isn’t in the set or is the last in the set when the Next button is clicked, the first one in the set will be selected. Shift-click on the Next button will cycle to the previous map in the set. It will wrap around to the last map.
Map window: This window displays the numbered relative positions of the locations with the found locations colored green. If there are stable locations within the map area, they will be displayed with a tiny horse head icon. If your current location is within this area, it will be displayed as a red dot (click Map to refresh the position). If the current item has a location in the description, it will display as a blue dot.
 Mousing over map locations will display their name if available. Clicking on a map location will set it as the current target and select it on the Item menu. Clicking on the Map or Heading button will update the map.
Compass window: This is an optional window that can be toggled on or off with the “/dlw c” command. It displays a compass graphic with 16 directional points. When a heading is active, a red dot will be displayed on the edge of the compass to show the target direction and the distance will be displayed in the center. When the target is reached, the red dot will move to the center. This window can also be opened by Shift-clicking on the Heading button.
There is an optional click panel that can be layered on top of the compass with the toggle command “/dlw cc”. Clicking on this panel will update the heading information the same as the Heading button in the main window. The Compass window defaults to displaying in the center of the screen, but can be dragged to a different position. Shift-clicking on the panel will perform a Nearest action instead of a Heading action.
Notes: The easiest way to use this tool is to go to the zone where the collection is found, select the Map and Area, and click the Nearest button to find a nearby item. Head in the direction given, periodically clicking on Heading to get updated distance and direction. When you arrive at the location, the Heading message will say that it is ‘here’. Collect the item, open the Check List window (if not already open), and click on Heading again to mark it on the check list (unless inside an instance without coordinates, which requires a manual check). Then click Nearest again to find the next item. After the last item is found, click the Done checkbox to mark it as complete. Sometimes you can tell from the map that the nearest location isn’t the most efficient path to follow.
If you happen upon a game item in a different collection, you can use the “Find what’s here” button to switch to it. The progress in the current collection check list will still be saved and you can return to it later. The “Save Item” button and “Restore Item” button make it simple to switch between collections.
When working on a collection that is a deed, all you can see in the Quest Tracker is the number of items collected, not which items are left, so a Check List should be used to keep track of visited locations. If you make a mistake in checking an item, you may have to revisit many of the locations to verify them, so be careful to be accurate.
If any mistakes or missing data are found, please send corrections to laurenstreich4@gmail.com and I will update the plugin. 
Known Issues: The current list of collections is growing and will be updated. Sometimes the map window isn’t automatically updated when a new area is selected (click the Map button to update).
